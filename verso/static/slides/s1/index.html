의미 방정식은 왜 함수를 하나로 정하는가

Reynolds, Theories of Programming Languages 1장 · 시리즈 1/9

1장의 정수식 의미를 대수로 다시 읽는다. 다섯 막이다: 트리 위의 계산, 범주의 말, 유일한 fold, 의미, free algebra와 대입. 청중은 집합·함수·귀납을 읽을 수 있고 범주론은 처음이라고 가정한다. 주황은 구문, 파랑은 계산된 값, 보라는 정리가 주는 사상이다.

3. 유일한 fold

규칙 묶음 하나가 계산 함수를 정확히 하나 정하는가?

정리 1. Exp는 initial algebra다

정리 · initiality

점선은 "보편 성질이 존재와 유일성을 주는 사상"이다. 시리즈 내내 같은 뜻으로 쓴다.

"모든 algebra"가 핵심이다. 값이든 크기든 괄호 출력이든, Exp에서 나가는 hom은 하나뿐이다. 앞의 세 트리 계산이 바로 세 fold였다. 이런 성질을 가진 algebra를 initial algebra라 부른다. Reynolds가 1.1절에서 "many-sorted initial algebra"라고 한 것이 이것이다.

보편 성질 한 줄, 법칙 셋

h = \fold_\alpha\quad\Longleftrightarrow\quad h\circ\inn = \alpha\circ Fh

법칙식보편 성질에 넣는 것
computation\fold_\alpha\circ\inn = \alpha\circ F\fold_\alphah := \fold_\alpha (⇒)
reflection\fold_{\inn} = \id_{\Exp}h := \id (⇐)
fusionk\alpha = \beta Fk\ \Rightarrow\ k\circ\fold_\alpha = \fold_\betah := k\circ\fold_\alpha (⇐)

reflection과 fusion은 "같은 곳으로 가는 hom은 하나"라는 유일성의 응용이다. 출발점이 initial일 때만 쓸 수 있다.

computation은 fold를 한 층 계산하는 규칙이고, Reynolds의 의미 방정식이 바로 이 꼴이다. reflection은 구문 algebra로 접으면 트리가 그대로 돌아온다는 것이다. fusion은 fold 뒤에 hom을 붙이면 다시 fold라는 것이다. 출발점이 initial이 아닌 algebra에서는 "같은 곳으로 가는 hom은 같다"가 거짓이다. 원소 0, 1에 모든 연산이 0을 주는 algebra에서는 항등과 상수 0이 둘 다 hom이다.

유일성은 트리 높이에 대한 귀납이다. 잎에서는 hom 조건이 값을 바로 정하고, 노드에서는 자식이 같으면 부모도 같다. 존재는 같은 세 줄을 재귀 정의로 읽은 것이다. 재귀가 끝나려면 트리가 유한해야 하고(가), 각 트리에 적용할 줄이 하나로 정해지려면 분해가 유일해야 한다(나). 다음 두 장은 각 조건을 하나씩 깨뜨린다.

괄호 없는 문자열은 initial이 아니었지만, 복합식마다 괄호를 씌우면 분해가 다시 하나가 된다. 그러면 Paren도 initial이고, 두 initial algebra 사이에는 생성자를 보존하는 번역이 정확히 하나씩 있으며 왕복은 항등이다. Reynolds p.6은 완전 괄호 중위 표기, 괄호를 쓴 전위 표기, 트리 세 표현을 같은 조건을 만족하는 예로 든다. "abstract syntax는 표현과 무관하다"는 말의 정확한 형태가 이것이다. 단, 둘 다 같은 F에 대해 initial임을 따로 보여야 한다. carrier는 문법이 생성한 문자열만이어야 하고, 잎의 표기가 서로 겹치면 안 된다. 예를 들어 변수 이름 "2"를 허용하면 var와 lit의 출력이 같아진다. 괄호 없는 Str처럼 initial이 아닌 표현에는 적용되지 않는다. Lean의 showAlg는 임의의 문자열 이름을 허용하므로 print/parse 역함수를 검증한 것이 아니다.

정수식과 단언: 두 sort의 initial algebra

정의 · 작은 단언 언어: I는 정수식, Q는 단언

G(I, Q) = \bigl(F I,\ \ I^2 + Q + Q^2 + \Var\times Q\bigr),\qquad G : \Sets^2\to\Sets^2

Q의 칸생성자
I^2두 정수식의 등식
Q,\ Q^2¬, ∧
\Var\times Q변수 v로 묶는 \forall_v

initial G-algebra가 (정수식, 단언)의 쌍이고, fold는 두 의미 함수를 한 번에 정한다. Reynolds가 1.1절에서 "many-sorted initial algebra"라고 부른 것이다.

true/false와 다른 비교·논리 연산은 생략했다. 함수 쌍 (f, g)에 대해 등식 칸은 f×f, 논리 칸은 g와 g×g, ∀ 칸은 id×g가 작용한다. 단언은 정수식을 참조하지만 정수식은 단언을 참조하지 않는다.

∀도 의미에서는 연산 하나다

정의 · 의미 algebra의 두 carrier

\Sem_I = \Sigma\to\mathbb Z,\qquad \Sem_Q = \Sigma\to\{\mathrm{false},\mathrm{true}\} \forall_v(\phi)(\sigma)\iff\forall n\in\mathbb Z.\ \phi([\sigma\mid v:n])

(\semfn_I,\ \semfn_Q) = \fold_{(\Sem_I,\ \Sem_Q)}

의미 평가의 재귀는 \forall_v 연산으로 직접 정한다. 자유 변수에 대입할 때는 포획을 피하는 이름 바꾸기가 추가로 필요하다(다음 장).

binder가 있으면 대입에 이름 바꾸기가 필요하다

반례 · 그대로 대입하면 변수가 붙잡힌다

(\forall x.\ x = y)/[y\mapsto x]를 그대로 바꾸면 \forall x.\ x = x. 자유 변수였던 y 자리의 x가 \forall x에 묶였다.

묶인 x를 먼저 z로 바꾸면 \forall z.\ z = x로 올바르다. binder가 있는 대입은 이름이 붙은 생성자를 그대로 보존하는 hom이 아니다.

Reynolds 1.4절이 자유 변수, 대입, 이름 바꾸기를 다룬다(Prop 1.3 Substitution Theorem). binder와 대입을 함께 다루는 algebra 이론으로 Fiore–Plotkin–Turi(1999)가 있다.

자연수의 재귀 정리도 같은 그림이다

(\mathbb{N}, 0, \mathrm{succ})는 F X = 1 + X의 initial algebra다.

\forall (A, a_0, f).\ \exists!\, h : \mathbb{N} \to A.\quad h(0) = a_0,\ \ h(n + 1) = f(h(n))

Dedekind의 재귀 정리. S2의 Kleene 정리는 같은 반복을 원소 수준에서 쓴다.

표준 1차 논리와 Reynolds 1장의 차이

표준 1차 논리는 구조 M = (D, I)를 바꿔 가며 참을 정의한다(Tarski).

Reynolds 1장은 정수라는 모델 하나에 고정한다. 그래서 valid는 "그 모델의 모든 상태에서 참"이다.
