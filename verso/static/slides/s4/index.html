S4. fail과 합성

실패한 계산은 다음 명령을 실행하지 않는다

Reynolds, Theories of Programming Languages 5.1 · 시리즈 4/9

S2의 f⊥⊥를 실패까지 넓히고, 그 확장이 S1의 free algebra와 같은 보편 성질에서 나온다는 것을 본다. 다섯 막이다: 결과 공간, free 확장, 세 법칙, 실패하는 while, 지역 변수.

같은 루프, 세 결과

예 · 러닝 예제

\cmd{while}\ x\ne0\ \cmd{do}\ \cmd{if}\ x=1\ \cmd{then}\ \cmd{fail}\ \cmd{else}\ x:=x-2

초깃값실행결과
x=66\to4\to2\to0정상 종료, x=0
x=55\to3\to1\to\cmd{fail}실패, x=1
x=-2-2\to-4\to-6\to\cdots비종료

S2의 루프에 실패 분기 하나를 더했다. 실패는 관찰된 사건이고 비종료는 아직 결과가 없는 것이므로 서로 다른 결과여야 한다.

S2에서는 홀수 초깃값이 음수로 내려가 끝나지 않았다. 이제 x가 1이 되는 순간 fail이 루프를 끊고, 그 시점의 상태를 결과로 남긴다. 같은 명령이 세 종류의 결과를 낸다.

Reynolds의 문제: fail은 결과를 정해야 한다

반례 · Σ → Σ로 두면

\sem{c_0;c_1}\sigma = \sem{c_1}(\sem{c_0}\sigma)

\sem{c_1}이 상수 함수이면 c_0의 실패가 결과에서 사라진다.

S2의 해법을 다시 쓴다

\sem{c_0;c_1}\sigma = \ext{\sem{c_1}}(\sem{c_0}\sigma)

\ext{f}(\bot) = \bot: 비종료는 뒤 명령이 무엇이든 전파된다. 실패도 같은 방식으로 전파하면 된다.

5.1절 첫머리의 관찰이다. 실패를 상태 하나로 표현하면 뒤 명령이 그 상태를 덮어쓸 수 있다. 비종료도 같은 문제였고, S2는 결과 공간에 ⊥를 더한 뒤 ⊥를 그대로 넘기는 확장으로 풀었다. 오늘은 같은 일을 실패 결과에 한다.

순차 합성 = 확장 뒤 합성

그냥 ⟦d⟧∘⟦c⟧라고 쓰면 타입이 맞지 않는다. ⟦c⟧의 출력은 (Σ+Σ)⊥이고 ⟦d⟧의 입력은 Σ다. 확장이 이 타입 차이를 메운다. 셋째 줄이 핵심이다: x:=9의 확장은 실패 결과를 그대로 돌려준다.

같은 흡수, 깨지는 등식 하나

등식fail이 없을 때fail이 있을 때
\cmd{fail};c\equiv\cmd{fail}—성립: c^*(a\sigma) = a\sigma
\cmd{loop};c\equiv\cmd{loop}성립성립: c^*(\bot) = \bot
c;\cmd{loop}\equiv\cmd{loop}성립깨짐: c=\cmd{fail}이면 a\sigma\ne\bot

loop은 영원히 도는 명령. 셋째 등식은 Reynolds p.100의 예다. 언어에 fail 하나를 더하면 상관없어 보이던 등식이 깨진다.

fail이 없을 때 c;loop는 c가 끝나면 loop가 돌고 c가 안 끝나면 그대로 비종료였으니 항상 ⊥였다. fail이 들어오면 세 번째 경우가 생긴다. c가 실패하면 loop는 실행되지 않고 실패가 남는다. 결과 공간을 바꾸는 확장은 그 언어의 모든 등식을 다시 확인하게 만든다.

정리 2. Kleisli triple의 세 법칙

실패를 전파하는 것도, 실패를 잡아 처리하는 것도 free 대상에서 나가는 유일한 사상이다. 달라지는 것은 목적지 algebra의 상수다. 효과를 "연산과 그 해석"으로 보는 관점의 가장 작은 예다. Reynolds 5.1에는 catch가 없다. 5.8의 catchin에서 다시 만난다.

4. 실패하는 while

실패하는 루프의 의미도 최소 고정점으로 얻는가?

펼침 함수와 근사

정의 · F : (Σ → T_Σ Σ) → (Σ → T_Σ Σ)

F(h)(\sigma)=\begin{cases}n(\sigma)&\sigma x=0\\a(\sigma)&\sigma x=1\\h(\sigma[x\mapsto\sigma x-2])&\text{그 밖}\end{cases}

F^n\botx=0x=1x=2x=3x=4x<0
F^0\bot\bot\bot\bot\bot\bot\bot
F^1\botn_0a_1\bot\bot\bot\bot
F^2\botn_0a_1n_0a_1\bot\bot
F^3\botn_0a_1n_0a_1n_0\bot

n_0 = n(\sigma[x\mapsto0]), a_1 = a(\sigma[x\mapsto1]). 매 단계 두 초깃값이 확정되고 음수는 끝까지 ⊥다.

S2의 표와 같은 방식이다. F는 연속이므로 Kleene 정리로 ⟦while⟧ = YF = ⊔Fⁿ⊥로 정의한다. x=0과 x=1은 한 번 펼치면 결과가 나오고, 한 단계마다 2씩 더 큰 초깃값이 확정된다.

최소 해: 짝수·홀수·음수

W = YF

W(\sigma)=\begin{cases}n(\sigma[x\mapsto0])&\sigma x\ge0,\ \text{짝수}\\a(\sigma[x\mapsto1])&\sigma x>0,\ \text{홀수}\\\bot&\sigma x<0\end{cases}

F(W)= W닫힌 꼴을 대입
F(h) = h\Rightarrow F^n\bot\sqsubseteq hn에 대한 귀납 (Park)
W = \lub_n F^n\bot\sqsubseteq h상한의 최소성

✔ approx_eq · W_fixed · W_least (구체적인 flat 순서) · ✘ 함수 공간 domain과 F의 연속성

x=5에서 시작하면 홀수 줄로 내려가 x=1에서 실패한다. 처음 표의 세 결과가 이 닫힌 꼴의 세 줄이다. 결과 공간이 바뀌어도 while의 정의 방식은 S2 그대로다.

5. 지역 변수

실패 상태에 남은 지역 변수의 값은 어떻게 해야 하는가?

이름만 다른 두 프로그램

예 · P = x:=0; newvar x:=1 in fail

\text{지역 } x \text{가 1인 채 실패} \Rightarrow\ a([\sigma\mid x:\chg{1}])

예 · P′ = x:=0; newvar y:=1 in fail

\text{지역 } y \text{가 1인 채 실패} \Rightarrow\ a([\sigma\mid x:0\mid y:\chg{1}])

반례 · 복원을 정상 결과에만 붙이면

묶인 이름만 다른 두 프로그램(y는 fresh)이 서로 다른 실패 상태를 낸다. 의미는 이름 바꾸기에 불변이어야 한다.

Reynolds p.99의 예다. newvar는 블록이 끝날 때 바깥 변수의 값을 되돌려야 하는데, 복원 함수를 별표 확장으로 붙이면 정상 결과만 복원되고 실패 결과는 지역 값을 그대로 품는다. 그러면 묶인 변수의 이름이 결과에 새어 나온다. S1 부록에서 binder가 있는 대입에 이름 바꾸기가 필요했던 것과 같은 원리다: 묶인 이름은 의미에 드러나면 안 된다.

f† = (f+f)⊥: 정상과 실패 양쪽을 복원

정의 · f : Σ → Σ
f^\dagger(n(\sigma))= n(f\sigma)
f^\dagger(a(\sigma))= a(f\sigma)
f^\dagger(\bot)= \bot

\sem{\cmd{newvar}\ v:=e\ \cmd{in}\ c}\sigma = r_\sigma^\dagger\bigl(\sem{c}[\sigma\mid v:\sem{e}\sigma]\bigr)

반례 · 고정 E의 functor 작용과 다르다

T_\Sigma f = (f + \id_\Sigma)_\bot,\qquad T_\Sigma f(a\sigma) = a\sigma f^\dagger = (f + f)_\bot

r_\sigma(\sigma') = [\sigma'\mid v:\sigma v]. (X, E)\mapsto(X+E)_\bot를 두 인자의 functor로 보면 f^\dagger는 (f, f)의 작용이다.

†는 정상 상태와 실패 상태 모두에 복원 함수를 적용한다. 앞 장의 P와 P′는 이제 둘 다 a([\sigma\mid x:0])를 낸다. 고정된 E에 대한 functor 작용 T_\Sigma f는 실패 쪽을 건드리지 않으므로 여기에 쓸 수 없다. 실패 표지 E도 움직이는 두 인자 functor의 대각선 작용이 †다. S7에서 resumption 위의 †로 다시 쓴다.

fail이 있을 때의 명세 (p.100)

정의 · f : Σ → (Σ+Σ)⊥

\PC_E(p,q)=\{f\mid\forall\sigma\in p,\tau.\ f\sigma=n\tau\Rightarrow\tau\in q\} \TC_E(p,q)=\{f\mid\forall\sigma\in p.\ \exists\tau\in q.\ f\sigma=n\tau\}

\{\mathrm{true}\}\ \cmd{fail}\ \{\mathrm{false}\},\qquad[\mathrm{false}]\ \cmd{fail}\ [\mathrm{false}]

Reynolds의 관례: 부분 정확성은 실패를 비종료처럼 허용하고, 전체 정확성은 금지한다. 실패를 ⊥와 같은 원소로 합치는 것은 아니다.

M1–M3를 세 경우로 확인하기

입력 r(g^*\circ f)^*(r)(g^*\circ f^*)(r)
n(x)g^*(f(x))g^*(f(x))
a(e)a(e)g^*(a(e)) = a(e)
\bot\botg^*(\bot) = \bot

M1: f^*(n(x)) = f(x). M2: (\eta_X)^*는 세 경우 모두 입력을 그대로 둔다. Lean의 extend_assoc가 이 표의 계산이다.

lifting은 E가 빈 free 구성

\CPO(X_\bot,\ A)\ \cong\ \Pre(X,\ UA),\qquad \bar g(x) = g(x),\quad \bar g(\bot) = \bot_A

E=\varnothing이면 C_E는 \CPO이고 L_E X = X_\bot. S2의 \ext{f}가 이 adjunction의 확장이다. X에 최소 원소가 있어도 새 ⊥를 하나 더 붙인다.

new 블록의 식

\mathrm{init}(\sigma) = [\sigma\mid v:\sem{e}\sigma],\qquad r_\sigma(\tau) = [\tau\mid v:\sigma v] \sem{\cmd{newvar}\ v:=e\ \cmd{in}\ c}(\sigma) = r_\sigma^\dagger\bigl(\sem{c}(\mathrm{init}(\sigma))\bigr)

블록이 정상으로 끝나든 실패하든 바깥 v를 되돌린다. 비종료면 †의 strict 분기로 ⊥가 남는다.

Lean의 extend

/-- 정상 결과만 다음 계산에 넘긴다. 실패와 ⊥는 그대로 둔다. -/ def extend {E X Y : Type} (f : X → Result E Y) : Result E X → Result E Y | none => none | some (.inl x) => f x | some (.inr e) => abort e

✔ 임의의 Type E, X, Y에서 정의 · ✘ 순서와 연속성

모든 monad는 adjunction에서 나온다 (진술)

\mu_X = (\id_{TX})^* : T(TX)\to TX,\qquad F_T\dashv U_T : \mathcal C^T\to\mathcal C,\qquad U_T F_T = T

\mathcal C^T의 대상은 a\circ\eta = \id, a\circ\mu = a\circ Ta인 a : TA\to A(Eilenberg–Moore algebra). 이 사실만으로 monad가 유한 개의 연산과 방정식으로 제시된다는 결론은 나오지 않는다.
