\sem{\cmd{while}\ b\ \cmd{do}\ c}\,\sigma = \begin{cases} \ext{\chg{\sem{\cmd{while}\ b\ \cmd{do}\ c}}}(\sem{c}\,\sigma) & \sem{b}\sigma = \mathrm{true} \\ \sigma & \text{그 밖} \end{cases}

노란 칸이 왼쪽 전체다. 해가 여럿이면 어느 것을 의미로 고르는가? 고른 해는 왜 존재하는가?

Reynolds는 이 식을 의미 방정식이라고 부르지 않는다. 부분식의 의미만으로 쓰이지 않았기 때문이다(2.2절). 오늘은 이 식을 함수에 대한 방정식 W = F(W)로 읽고, 해들 사이에 순서를 주어 가장 작은 해를 고른다. 끝에서 그렇게 고른 해로 while을 다시 fold 안에 넣는다.

while은 W = F(W)를 만족한다

정의 · 펼침 함수 F

F(f)(\sigma) = \begin{cases} \ext{f}(\sem{c}\,\sigma) & \sem{b}\,\sigma = \mathrm{true} \\ \sigma & \text{그 밖} \end{cases} \sem{\cmd{while}\ b\ \cmd{do}\ c} = F\bigl(\sem{\cmd{while}\ b\ \cmd{do}\ c}\bigr)

예 · 러닝 예제 W = \cmd{while}\ x\ne 0\ \cmd{do}\ x := x - 2

F는 함수를 받아 함수를 돌려준다. while의 의미는 F의 고정점이어야 한다.

F의 정의역과 공역은 Σ → Σ⊥ 전체다. 러닝 예제에서 몸체 x := x − 2는 ⊥를 내지 않으므로 f⊥⊥가 f로 바로 바뀐다.

"가장 작은 해가 올바른 의미"는 정리가 아니라 선택이다. Reynolds도 while에 대한 다른 엄밀한 정의가 없으므로 증명할 수 없다고 말하고, wₙ으로 직관을 준다. 실행이 b를 정확히 n번 검사하고 끝나면 i < n인 wᵢ는 ⊥, i ≥ n인 wᵢ는 같은 결과다. 끝나지 않으면 모든 wᵢ가 ⊥다.

Park 귀납은 최소 고정점이 무엇인지 몰라도 그보다 큰 것을 찾으면 쓸 수 있다. 오른쪽 사각형의 오른쪽 변이 가정 f(y) ⊑ y, 왼쪽 변이 Kleene가 준 등식, 아래 점선이 결론이다. S1에서 "initial에서 같은 algebra로 가는 hom은 하나"였던 것이 여기서는 "Yf에서 y로 가는 ⊑가 있다"로 바뀐다. while true do skip의 의미가 ⊥라는 1막의 직관이 이렇게 확인된다: 모든 상태를 ⊥로 보내는 함수는 항등 함수 F의 고정점이므로 의미는 그 아래이고, 그것이 최소 원소이므로 같다.

while도 fold가 된다

정의 · D = Σ → Σ⊥, β : Σ → 𝔹, γ ∈ D일 때 while 연산을 먼저 정한다

\mathrm{while}_D(\beta, \gamma) := Y\,F_{\beta,\gamma},\qquad F_{\beta,\gamma}(h)(\sigma) = \begin{cases}\ext{h}(\gamma\sigma) & \beta\sigma = \mathrm{true}\\ \sigma & \text{그 밖}\end{cases}

\sem{\cmd{while}\ b\ \cmd{do}\ c} = \mathrm{while}_D\bigl(\sem{b},\ \sem{c}\bigr)

오른쪽에는 부분식의 의미만 있다. 다른 명령 연산까지 정하면 명령 signature의 의미 algebra가 되고, 유한 명령 구문의 initiality(S1과 같은 원리)로 전체 의미가 유일한 fold가 된다. 최소 해 선택은 이 algebra의 정의에 들어 있다.

S1의 질문 1로 돌아간다. 펼침 방정식은 syntax-directed가 아니었지만, Y로 최소 해를 골라 while 연산을 정의하면 의미 방정식이 syntax-directed가 된다. 그러면 S1의 initiality가 명령 전체에 적용된다. 주의할 점 둘. 첫째, 최소 해를 고르는 선택은 구문의 initiality에서 나오지 않는다. 둘째, while 연산 내부의 Y 계산은 구조적 재귀가 아니라 근사의 상한이다.

soundness와 full abstraction (Reynolds 2.8절)

정의 · 관찰과 문맥

문맥 C와 허용 관찰 O의 집합을 고정한다.

\semfn가 sound: \sem{c} = \sem{c'}이면 모든 C, O에서 O(C[c]) = O(C[c']).

fully abstract: 위의 "이면"이 "일 때 그리고 그때만"이다.

x := x + 1\,;\,x := x + 1과 x := x + 2는 같은 의미지만 실행 시간을 허용 관찰에 넣으면 구별된다. 그래서 관찰의 범위를 먼저 고정한다.

S1의 congruence와 같은 질문이다: 의미가 같은 부분을 문맥 안에서 바꿔도 관찰이 같은가. S3에서 말하는 추론 규칙의 soundness와는 다른 뜻이다.
